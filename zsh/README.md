# Zsh configuration

A small, conventional [Oh My Zsh](https://ohmyz.sh/) configuration with XDG state, fzf widgets, and a Starship prompt.

## Install

Oh My Zsh is required and must already be installed at `~/.oh-my-zsh`, or at the path supplied in `ZSH`. Startup does not install or update it.

The startup files are linked individually. Do **not** set `ZDOTDIR`; that would make Zsh search for later startup files in another directory.

```sh
repo="$HOME/path/to/dotfiles"
mkdir -p "$HOME/.config"
ln -s "$repo/zsh" "$HOME/.config/zsh"
ln -s "$repo/zsh/core/zshenv" "$HOME/.zshenv"
ln -s "$repo/zsh/core/zprofile" "$HOME/.zprofile"
ln -s "$repo/zsh/zshrc" "$HOME/.zshrc"
ln -s "$repo/starship" "$HOME/.config/starship"
```

Back up or remove existing files before creating the links. `core/zshenv` preserves caller-provided XDG variables and otherwise uses `~/.config`, `~/.cache`, and `~/.local/state`. History and completion metadata are stored in private XDG directories.

## Dependencies

The Oh My Zsh plugins are a static list, not capability-discovered. Install the third-party `fast-syntax-highlighting` plugin manually as described in [`PLUGINS.md`](./PLUGINS.md). A missing static plugin may produce an Oh My Zsh warning, and a missing command may disable or degrade its plugin feature.

Useful tools include `bat`, `eza`, `fd`, `fzf`, `ripgrep`, `starship`, `thefuck`, and `zoxide`. Direct initialization of fzf and Starship is command-guarded. The configuration supports modern fzf releases that provide `fzf --zsh`; older-fzf shell-path scanning and compatibility fallbacks are intentionally not supported.

Starship reads `~/.config/starship/starship.toml` by default. A Nerd Font is recommended for its symbols.

## Plugin and key behavior

Oh My Zsh owns completion initialization. Its fzf plugin is omitted because `fzf --zsh` is initialized directly. `fast-syntax-highlighting` stays last in the static plugin list for command coloring. `zsh-autosuggestions` is enabled before it (history, then completion; accept with `→` or `End`). Automatic Oh My Zsh updates are disabled.

| Key | Action |
| --- | --- |
| `Ctrl+F` | Pick non-hidden files and append safely shell-escaped paths |
| `Ctrl+T` | Standard modern-fzf file picker when fzf is available |
| `Esc Esc` | Correct the previous command when TheFuck and its OMZ plugin work |

`fk` reuses the `fuck` alias generated by the Oh My Zsh plugin; it does not run TheFuck a second time.

## Verify

From the repository root:

```sh
for file in zsh/core/* zsh/custom/*.zsh zsh/zshrc; do
  zsh -n "$file" || exit 1
done
env -i HOME="$HOME" PATH=/usr/bin:/bin TERM=xterm-256color zsh -dlic exit
starship print-config >/dev/null
```
